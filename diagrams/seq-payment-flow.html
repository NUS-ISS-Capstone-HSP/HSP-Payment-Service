1. Create Payment + Process Callback (US-6.1: 在线支付)

sequenceDiagram
    actor Customer as 👤 Customer
    participant GW as 🌐 API Gateway
    participant PS as 💰 Payment Service
(gRPC :50051)
    participant WX as 💬 WeChat Pay
(Mock / Simulated)
    participant DB as 🗄️ MySQL
(hsp_payment)

    Customer->>GW: POST /api/finance/v1/payments
{order_id, amount, method=WECHAT}
    GW->>GW: JWT Auth + RBAC check
    GW->>PS: gRPC CreatePayment
(order_id, amount, method)

    PS->>PS: Validate: order_id + amount > 0
    PS->>DB: Check existing payment for order_id
    DB-->>PS: No existing payment

    alt Duplicate payment
        PS-->>GW: 409: payment already exists
        GW-->>Customer: 409 Conflict
    else New payment
        PS->>PS: Generate UUID payment_id
        PS->>PS: Set status = PENDING
        PS->>DB: INSERT INTO payments VALUES (...)
        DB-->>PS: Row inserted
        PS-->>GW: {payment_id, status=PENDING, ...}
        GW-->>Customer: 201 Created
{payment_id, QR/redirect link}
    end

    Note over WX: Customer completes payment
via WeChat Pay

    WX->>GW: POST /api/finance/v1/payments/callback
{payment_id, success=true}
    GW->>PS: gRPC ProcessPaymentCallback
(payment_id, success)

    PS->>DB: SELECT * FROM payments WHERE payment_id=?
    DB-->>PS: Payment record (status=PENDING)

    alt Payment not found
        PS-->>GW: NOT_FOUND
    else Success callback
        PS->>PS: Set status = COMPLETED
        PS->>PS: Set paid_at = now()
        PS->>DB: UPDATE payments SET status=?, paid_at=?
        DB-->>PS: Row updated
        PS-->>GW: {payment: {status=COMPLETED, ...}}
        GW-->>WX: 200 OK
    else Failed callback
        PS->>PS: Set status = FAILED
        PS->>DB: UPDATE payments SET status=?
        PS-->>GW: {payment: {status=FAILED, ...}}
    end

2. Worker Income Calculation (US-6.3: 师傅收入自动结算)

sequenceDiagram
    actor Admin as 👤 Admin / Owner
    participant GW as 🌐 API Gateway
    participant PS as 💰 Payment Service
(gRPC :50051)
    participant DB as 🗄️ MySQL
(hsp_payment)

    Admin->>GW: POST /api/finance/v1/incomes/calculate
{order_id, worker_id, order_amount}
    GW->>GW: JWT Auth + RBAC (OWNER only)
    GW->>PS: gRPC CalculateWorkerIncome
(order_id, worker_id, order_amount)

    PS->>PS: Validate: order_id + worker_id present

    alt Missing fields
        PS-->>GW: INVALID_ARGUMENT
        GW-->>Admin: 400 Bad Request
    else Valid
        PS->>PS: commission_rate = 0.7 (default)
        PS->>PS: worker_amount = order_amount × 0.7
Example: ¥500.00 × 0.7 = ¥350.00
        PS->>DB: INSERT INTO worker_incomes
(order_id, worker_id, order_amount,
commission_rate, worker_amount)
        DB-->>PS: Row inserted
        PS-->>GW: {income: {income_id, worker_amount=350.00, ...}}
        GW-->>Admin: 201 Created
{income_id, worker_amount, commission_rate}
    end

3. Revenue Summary Query (US-6.2: 收入统计)

sequenceDiagram
    actor Admin as 👤 Admin / Owner
    participant GW as 🌐 API Gateway
    participant PS as 💰 Payment Service
    participant DB as 🗄️ MySQL

    Admin->>GW: GET /api/finance/v1/summary
?start_date=2026-01&end_date=2026-06
    GW->>GW: JWT Auth + RBAC (OWNER only)
    GW->>PS: gRPC GetRevenueSummary
(start_date, end_date)

    PS->>DB: SELECT SUM(amount)
FROM payments WHERE status=COMPLETED
AND paid_at BETWEEN start AND end
    DB-->>PS: Total revenue: ¥15,200.00

    PS->>DB: SELECT SUM(worker_amount)
FROM worker_incomes
WHERE created_at BETWEEN start AND end
    DB-->>PS: Total payout: ¥10,640.00

    PS->>PS: net_income = 15200 - 10640 = 4560.00

    PS->>DB: COUNT total orders, COUNT paid orders
    DB-->>PS: total=45, paid=38

    PS-->>GW: {summary: {total_revenue, total_worker_payout, net_income, total_orders, paid_orders}}
    GW-->>Admin: 200 OK
{total_revenue, net_income, ...}
